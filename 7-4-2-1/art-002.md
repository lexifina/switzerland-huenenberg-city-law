# Art. 2 Grundgebühr, Art. 20 Abs. 3
1 % Gemeindestrassenanteil:
((Gemeindestrassenfläche x 3) x 100) / ((Bauzonenfläche x 1) + (Gemeindestrassenfläche x 3) + (Kantonsstrassenfläche x 3))
=
(84'800 x 3) x 100 / ((1'510'750 x 1) + (84'800 x 3) + (32'100 x 3))
=
13.67%
2 % Kantonsstrassenanteil:
((Kantonsstrassenfläche x 3) x 100) / ((Bauzonenfläche x 1) + (Gemeindestrassenfläche x 3) + (Kantonsstrassenfläche x 3))
=
((32'100 x 3) x 100) / ((1'510'750 x 1) + (84'800 x 3) + (32'100 x 3))
=
5.17%
